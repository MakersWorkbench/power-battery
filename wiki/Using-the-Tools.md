# Using the Tools

## Pick a tab, type values

Choose the tab for the job. Every tab starts with a working example already filled in, so you can see what a result looks like, then change the numbers to yours. Answers update as you type; there is no Calculate button.

## Prefixes

| Type | Means |
| --- | --- |
| `p` | pico, 10⁻¹² |
| `n` | nano, 10⁻⁹ |
| `u` | micro, 10⁻⁶ |
| `m` | milli, 10⁻³ |
| `k` | kilo, 10³ |
| `M` | mega, 10⁶ |

Examples: `470u` is 470 microfarads, `100k` is 100,000 ohms, `4k7` is 4,700 ohms. A capital `M` is mega and a lowercase `m` is milli. Fields labeled with a unit like mA or mm take a plain number in that unit.

## Engineering notation

Results are shown with the nearest prefix, so 0.0047 A reads **4.7 mA**.
